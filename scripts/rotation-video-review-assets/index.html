Проверка докрута на новых видео

Оцените только докрут акселя в момент первого касания. «Недокрут» включает пограничный q. Если ракурс, скорость или видимость не позволяют решить — выберите «Не видно / не уверен». Общую красоту и устойчивость приземления здесь не оцениваем.

Ответы модели скрыты, чтобы не влиять на оценку. Эти видео не использовались при обучении модели докрута.

Группа спортсмена

Назначьте каждому спортсмену один анонимный код (например, A, B, C). Для одного и того же спортсмена используйте один код во всех его видео. Имена не нужны.
