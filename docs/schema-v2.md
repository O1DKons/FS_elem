# Схема v2 и сохранение смысла данных

Версия базы: SQLite `PRAGMA user_version = 2`. Версия документа API: `schemaVersion = 2`. Версия исходного JSON остаётся 1 в неизменённых файлах `originals`.

| Таблица | Содержимое |
|---|---|
| `videos` | ID, порядок каталога, относительный путь к копии медиа и полный исходный JSON |
| `frame_times` | ID видео, индекс кадра с нуля, время в исходном файле; составной ключ |
| `attempts` | ID эпизода, видео, порядок, кадры/времена границ, группа повторов и полный JSON |
| `expert_labels` | Экспертная метка, ссылка на видео, необязательная ссылка на попытку, исходный текст и происхождение |
| `metadata` | Текущая ревизия/описание границ и отпечаток импорта |
| `revisions` | Полные документы каждой сохранённой ревизии новой базы |

JSON payload сохраняет дополнительные поля источника без переименования и потери. В индексированных колонках находятся данные для связей и запросов. Внешние ключи включены. Все метки импортированы на уровне видео, `attempt_id = NULL`: исходный документ не подтверждает, к какому размеченному эпизоду относится метка. Связи с будущими pose/метриками в этом блоке не создаются.

Сохранение проверяет целочисленную ревизию, уникальные ID, ссылки на видео, типы комментария/группы, диапазон и порядок кадров, соответствие секундам с допуском 20 микросекунд. Null-границы разрешены как черновики; у заданной временной отметки обязательно есть индекс кадра. Группа ограничена 200 символами, комментарий — 5000. Незнакомая версия документа отклоняется.

В старом каталоге длительность двух файлов округлена до сотых секунды. При проверке каталога допускается последний кадр до 10 мс за этой округлённой длительностью; исходное значение каталога не меняется. При проверке отметки определяющим остаётся существующий кадр с точным временем. Большее расхождение каталога блокирует импорт.

Импорт сохраняет все исходные JSON отдельными файлами, сверяет SHA256 источников/копий и повторно проверяет источник перед публикацией. Ошибка до публикации удаляет созданную временную папку. Проверяется физическое расположение путей с учётом символических ссылок. ID видео, отличающиеся только регистром, запрещены для переносимости между файловыми системами.

`none_stated` не является отрицательной экспертной меткой недокрута. Время — секунды файла; импорт не восстанавливает замедление. Полные обороты, тип элемента, докрут и подтверждение границ не выводятся из названия файла.
