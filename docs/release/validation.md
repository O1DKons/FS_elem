# Проверка RC1

На 3 октября 2026 проверены чистая установка и один полный анализ через интерфейс. Это прототип для тестирования.

- 14 проверок клиента, геометрии и отмены прошли; два сценария запоздалого ответа отмены отдельно проверены независимым исполнителем.
- В изолированной копии установлены публичные зависимости, проверены контрольные суммы ресурсов, сборка, готовность анализатора и остановка сервисов. Node 24.19.0, Python 3.12.12 / 3.9.25, pnpm 11.19.0; macOS 27.0, Apple Silicon M2.
- Первая сборка не прошла из-за трёх отсутствовавших shared-модулей. После исправления состава пакета сборка в той же установке прошла. Все 16 актуальных файлов интерфейса совпали с проверенной сборкой. Полный публичный пакет содержит дополнительные документы и тесты; отдельная повторная установка этого окончательного архива не выполнялась.
- Один настоящий анализ соревновательного проката длительностью 199,12 с завершился без ошибки за 722,76 с расчёта (723,44 с жизненного цикла задачи). Кэш результата не использовался. Получены три акселя: 2A, 2A, 1A. Все девять внутренних кандидатов совпали с сохранённым анализом по границам и классификации.
- Экспортировано 1 824 кадра позы. В настоящем интерфейсе проверены три карточки, переходы к элементам, скелет на исходном видео, включение/выключение скелета, отсутствие точек при пустой оценке и изменение окна до ширины 390 px. Исходные кадры и приватные снимки этой проверки не входят в публикацию.

Этот прокат знаком модели и пересекается с обучением. Проверка подтверждает воспроизводимость переноса и работу интерфейса; независимую точность, способность находить все прыжки и realtime она не подтверждает. Известна ошибка 1A → 2A на другом знакомом видео. Пустой результат может быть пропуском.

1A/2A — номинальные классы. Физическое вращение и недокрут не измеряются. Большие upstream-модели не распространяются в Git/ZIP; условия их применения описаны в [third-party.md](third-party.md). Исторический протокол установки: [installation-verification-v1.json](installation-verification-v1.json).
