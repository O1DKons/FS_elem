# Проверка кандидата RC3

Снимок подготовки на 4 октября 2026: подготовлены принятые safe-error исходники и новая проверенная production-сборка интерфейса. Локальные API/браузер прошли 15 проверок синтетических неуспешных задач; независимая проверка сохранённых свидетельств этого прохода принята с оговорками области проверки. Reviewer проверил receipts и снимки, а не повторял браузерный проход. На момент фиксации снимка отдельная проверка публичного allowlist-пакета ещё ожидается, публикация не выполнена. Поле `frozenPreparationStatusBeforePublication` в manifest описывает только это состояние; итоговую приёмку выпуска и факт публикации следует сверять с GitHub Release notes для тега RC3 через `releaseAcceptanceInGitHubNotes`. Снимок подготовки не утверждает постоянную неготовность позже опубликованной версии.

## Новая область проверки

Проверены сообщения о расхождении числа кадров, безопасный fallback при неизвестной/некорректной диагностике и восстановление failed-задачи по ссылке/последнему анализу. У таких задач нет предсказаний, результата или позы; API возвращает 409 для result/pose. Браузерные материалы сохранены приватно и не поставляются. Мобильное сообщение читается после обычной вертикальной прокрутки; видимость над сгибом первого экрана не заявляется. Независимая приёмка учитывает явное разрешённое исключение: на новом изолированном тестовом origin мог остаться один указатель на синтетическую задачу; восстановление этого указателя не заявляется. Рабочие origin и хранилища задач не менялись. Снимки браузера имеют JPEG/JFIF-содержимое при исторических именах .png; reviewer проверил фактическое содержимое, байты и пиксели не меняли.

Код и pure-интеграция проверены отдельно:11 серверных и 37 клиентских проверок с исполнением компонента TSX прошли; первоначальный новый wire-тест не импортировался из-за ошибки самого теста. После исправления только теста отдельно прошла одна проверка публичного клиента, без повтора успешных наборов. Новая production-сборка создана один раз на повторно использованных зависимостях того же компьютера. Это не чистая установка окончательного архива на новом устройстве.

Новых video/pose/ML запусков, обучения или измерений точности и скорости RC3 не было. Модели, пороги, частота выборки и ORT 4/1 остаются прежними. Проверка источника сохраняет остановку до декодирования downstream-ветвей/оценки моделей; существующие веса могут ранее читаться для проверки SHA. Copy/SHA существующих публичных моделей и demo-медиа не равны загрузке модели для анализа/NN или анализу новых исходных видео.

Далее сохранены результаты прежней RC2 с собственной датой и границами применимости; они не являются повторным тестом RC3.

# Историческая проверка RC2

Статус на 3 октября 2026: общая приёмка локальной платформы RC2 прошла. Точный состав поставки перечислен в `source-manifest.json`; опубликованный архив и его SHA-256 доступны в GitHub Release.

## Проверка интегрированного пакета

Одна production-сборка, проверка типов и 93 проверки прошли: 25 интерфейсных, 18 контрактных, 17 установки/запуска, 8 сервиса, 23 pipeline и 2 экспорта позы. Проверки не выполняли обучение или дополнительное распознавание. Отдельно прошла одна обычная загрузка всего видео через API без ручных границ прыжков и без pose-кэша.

Сохранённый анализ открывается по `/analysis?job=UUID`, после перезагрузки и кнопкой «Открыть последний анализ» без новой загрузки и распознавания. В браузере проверены исходное видео, карточки 2A/2A/1A, поза на исходных кадрах, неизменное время 7:13.76, мобильное окно 390 px и сообщение об отсутствующей задаче. Восстановление использует GET; новый файл для повторного анализа требуется отдельно. Независимая проверка приняла результаты API, ресурсы, код и четыре приватных снимка браузера. Взаимодействия с браузером выполнял владелец интерфейса; независимый reviewer проверил его снимки и receipts, а не повторял весь браузерный проход.

RC2 использовал проверенные зависимости на том же компьютере и прошёл offline-проверку готовности. Это не новая установка финального архива на другом устройстве. Чистая установка RC1 остаётся историческим свидетельством.

Время задачи включает ожидание и обработку после принятия загрузки. Для старых завершённых задач используется разность сохранённых времён завершения и создания; для старых активных задач без серверного времени значение неизвестно. Это не прогноз окончания. Новый файл для повторного анализа выбирается отдельно; восстановление результата не подделывает загрузку.

## Единственное сравнение скорости

На полном знакомом прокате comp44 длительностью 199,12 с выполнен один холодный запуск интегрированной платформы ORT 4/1 и сравнение с ранее сохранённым холодным RC1 ORT 2/1. Время pipeline: **722,760365 → 433,113428 с, −40,0751%**. Полный жизненный цикл новой задачи составил 433,755513 с (в интерфейсе 7:13.76). Внешний замер от момента перед POST до получения результата и позы — 435,124003 с; это другой интервал времени.

События и номинальные классы 2A/2A/1A сохранились. Проверены девять внутренних кандидатов, точное совпадение записанных координат, scores и масок, 198 кадров BGR; публичный экспорт позы содержит 1824 кадра, привязанных к источнику. Обе роли detector/pose в sparse/dense использовали CPU 4/1. Процессы распознавания завершились, сервер остался доступен для просмотра сохранённого результата.

Ранее отдельный эксперимент ORT 4/1 на том же источнике занял 402,174227 с (−44,3558%). Это дополнительное наблюдение, а не время запуска интегрированной платформы RC2.

Это упорядоченные наблюдения без повторов и перестановки порядка. Источник пересекается с историческим TRAIN. Они не подтверждают независимую точность, скорость на других видео, устойчивую оценку ускорения или realtime. Известная ошибка 1A → 2A на другом знакомом видео остаётся; отдельно выбранный пропущенный 1A другой записи соревнований не исправлен. Отсутствие найденных событий может быть пропуском.

## Граница публичного пакета

В пакет входят прежние очищенные веса, два новых профиля и принятый интерфейс. Модели, частота выборки и пороги не изменены. Новые семейные FIT-эксперименты не включаются. ONNX, FFmpeg, исходное видео comp44, приватные кадры, протоколы, job-артефакты, кэши и окружения исключены. На Pages остаются только два отдельно разрешённых демонстрационных ролика, без работающего сервиса анализа.

RC1 остаётся неизменным baseline и вариантом отката. Его чистая установка и полный браузерный анализ описаны в историческом [протоколе установки](installation-verification-v1.json). Исторические receipts RC1 не являются проверкой новой сборки RC2.

1,5 и 2,5 оборота — определения номинальных 1A/2A, а не измеренные физические обороты. Недокрут не измеряется. Условия upstream-компонентов: [third-party.md](third-party.md).
