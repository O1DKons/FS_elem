# FS_elem для Windows

Windows 10 или 11, 64-разрядная версия.

1. Скачайте FS_elem-Setup.exe со страницы выпуска.
2. Откройте установщик и нажмите «Установить».
3. Запустите FS_elem через ярлык на рабочем столе или в меню «Пуск».

Python, Node.js и другие программы отдельно устанавливать не нужно. При первом запуске FS_elem сам загрузит файлы анализа и покажет прогресс. Для этого нужен интернет; загрузка составляет около 308 МБ. Если сеть прервётся, нажмите «Повторить». Проверенные файлы сохранятся.

После подготовки откроется интерфейс в браузере: выберите видео и запустите анализ. Последующие запуски не требуют установки компонентов. Скорость анализа зависит от компьютера и длины видео.

Окно FS_elem управляет программой. Чтобы завершить работу, нажмите «Завершить» в этом окне. Закрытие вкладки браузера оставляет программу работающей.

Результаты сохраняются в папке FS_elem в данных вашего пользователя и остаются после удаления программы.

Это исследовательская система распознавания 1A/2A. Проверяйте результаты; достоверность физического докрута не установлена.
