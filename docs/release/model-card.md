# Axel release v1 model card

This release uses existing research weights. It proposes automatic Axel candidates and nominal 1A/2A on complete videos. Nominal 1.5/2.5 revolutions are definitions; physical airborne rotation, underrotation and protocol q/< /<< are unvalidated and returned as null.

Flight is an ExtraTrees classifier fitted on mixed public and personal-domain data (4690 background and 151 flight samples for this frozen group). Family has 33 Axel and 276 other training events and also historical personal-domain overlap. Nominal uses 23 public/competition events. These are training counts, not independent full-video accuracy. The historical flight experiment was not admitted as validated production improvement. Athlete independence and the goal70 accuracy target remain unverified; familiar competition sources overlap historical stage training. Empty output means no Axel detected, not proof none occurred.

The selected original flight/family/nominal SHA256 values are recorded alongside release hashes in the manifest. Flight and family release artifacts remove only `fold` metadata, retaining fitted model, preprocessing state and protocol hash. Nominal already has this minimal container and retains its original SHA. No training, scoring or fitted-state rewrite took place during packaging. Full structural/numeric comparisons and canonical-state hashes match before/after serialization. Canonical traversal includes all estimator attributes and Tree state and every named structured-array field; only unused padding bytes are excluded because raw flight joblib hashes vary across repeated loads of the same input. Synthetic mutation guards and code/environment hashes are bound in the sanitation receipt.

Private recordings, athlete mappings, training records, pose caches, original protocols and private paths are not distributed. Packaging uses only the three sanitized small artifacts. This metadata removal does not remove model memorization risk or establish dataset/model redistribution rights. The project has not assigned a new model license in this packaging step; preserve existing rights and inspect the upstream terms before commercial use or redistribution. See third-party.md. Skeleton points are actual sparse/dense observations with source PTS and displayed pixel geometry, not interpolated ground truth. Model scores are uncalibrated.
