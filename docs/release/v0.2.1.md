# FS_elem v0.2.1 — статус кандидата

Кандидат готовит общий локальный запуск для macOS 13+ Apple Silicon и Windows 10/11 x64, CPU. Добавлены Windows-вход FS_elem.cmd, платформенные замки и управляемые маркеры окружений, владеющий дочерними процессами launcher и Windows Job Object для дерева анализа. Версии моделей, пороги и ORT 4/1 не меняются. Архив содержит публичные исходники и прежний собранный интерфейс; Node, Python-окружения, FFmpeg и большие ONNX подготавливаются локально из закреплённых источников. Приватные веса и исходные записи не загружаются в GitHub.

Проверено на Mac: контролируемые сценарии запуска/завершения и исправленные тесты двух отключений IPC. Эти проверки не использовали настоящий SDK/SQLite и не подтверждают native Windows или запуск полного нового пакета. Прежние положительные сценарии сохранены без повторного прогона. v0.2.0 и его проверенные исторические записи остаются отдельным выпуском.

Подготовлено, но ещё не выполнено: Windows Server 2022 x64 CI с первой установкой, locked resolver/pip check, фактическими FFmpeg -version/-L, десятью backend-проверками владения и production HTTP-запуском/остановкой/повторным запуском. Native Mac-проверка миграции маркера и полного production-пакета также ожидает отдельного выполнения. Запуск через Проводник Windows 10/11 и полный UI-путь загрузки/отмены — отдельная desktop-проверка.

CI запускается автоматически только для ветки release/v0.2.1; основной main не меняется этим кандидатом. В push-проверке нет NN, FIT или загрузки настоящего видео на анализ. Такая загрузка создаёт задачу распознавания, поэтому отдельно разрешается только после принятия установки и жизненного цикла с точным видео, ресурсами и границами результата. На этой стадии этот этап отключён. Контролируемая отмена producer в backend-тестах и отмена всего launcher в HTTP smoke не равны отмене нового реального анализа в интерфейсе.

Для первой установки и следующих запусков: [Mac и общие зависимости](installation.md), [Windows](installation-windows.md), [короткая инструкция](quickstart.md). После подготовки видео и расчёт остаются локальными. Сохранённые примеры на Pages не выполняют новый анализ.
