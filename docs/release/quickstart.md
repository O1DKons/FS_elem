# FS_elem — инструкция тестировщика RC

Статус на 3 октября 2026: RC1 прошёл чистую установку, сборку, проверку ресурсов, запуск/остановку сервисов и один настоящий анализ полного проката через интерфейс. Получены 2A, 2A и 1A; обработка 199,12 с видео заняла 722,76 с расчёта. Видео знакомо модели и пересекается с обучением; независимая точность не подтверждена. [Состав и ограничения проверки](validation.md), [исторический протокол установки](installation-verification-v1.json). Проверяйте скачанный RC, а не статическую демонстрацию GitHub Pages.

## Установка и запуск

Требуются Mac с Apple Silicon, macOS 13 или новее, Node.js 24 с npm/npx и [uv](https://docs.astral.sh/uv/getting-started/installation/). Из корня скачанного пакета выполните команды из [полной инструкции установки](installation.md):

```sh
uv python install 3.12 3.9
npm run setup:release -- --science-python "$(uv python find 3.12)" --pose-python "$(uv python find 3.9)"
npm run check:release -- --science-python "$(uv python find 3.12)"
npm run start:release
```

Скрипты создают отдельные Python-окружения, устанавливают зависимости и загружают модели. В проверенной копии использовались Node 24.19.0, Python 3.12.12 / 3.9.25 и pnpm 11.19.0, без прежних окружений и кэшей. Один реальный анализ на этом окружении завершился успешно. При ошибке остановитесь и сохраните сообщение; не переходите к следующей команде. Проверка `check:release` не запускает распознавание.

Оставьте терминал открытым и перейдите на `http://127.0.0.1:5174/analysis`. При изменённом порте используйте адрес, напечатанный при запуске. Остановка обоих сервисов — Ctrl+C в этом терминале. Для RC используется локальный сервер Vite; эта инструкция не описывает размещение сервиса в интернете.

Перед анализом откройте `http://127.0.0.1:5174/api/analysis/health` (с поправкой на порт). Поле `inferenceAvailable` должно быть `true`. При `false` сохраните список `issues`: сервис ещё не готов к распознаванию. Успешный ответ health сам по себе не подтверждает качество анализа.

Импорт прежней базы для анализа своего видео не требуется: сервер создаёт пустое хранилище при первом запуске. В проверенной копии `/analysis` открылся, а health вернул `inferenceAvailable: true`; это подтверждает запуск и готовность ресурсов, но не успешное распознавание видео.

## Проверка двух видео

1. Возьмите два соревновательных видео обычной скорости с известными вам 1A и 2A. Форматы: MP4, MOV, M4V или WebM; каждый файл до 512 MiB. Для первого теста не используйте замедленный экспорт.
2. Выберите файл в области «Добавьте видео спортсмена», затем нажмите «Начать анализ». Дождитесь завершения первого видео перед загрузкой второго. Отметьте время запуска и завершения; не задавайте вручную границы прыжка.
3. Сверьте найденный интервал с видео. Запишите пропущенные аксели, лишние срабатывания и неверные названия. Нажатие на карточку результата или оранжевый участок временной шкалы должно переводить плеер к элементу.
4. После завершения включите «Показывать точки и связи». Проверьте совпадение точек с человеком на паузе, после перемотки и изменения размера окна. Если доступен обычный портретный ролик, проверьте также его ориентацию. В кадрах без подходящей оценки точки должны скрываться; появление скелета только после завершения допустимо.
5. Для отдельной проверки отмены запустите задачу и нажмите «Отменить». Дождитесь состояния `cancelled`; отмена не должна отображаться как успешный анализ.

## Как понимать ответ

| Состояние | Значение |
| --- | --- |
| `queued` / `running` | Ожидание / обработка. Процент относится к текущей стадии, если известен, и не является прогнозом окончания |
| `succeeded` | Анализ завершён; проверьте найденные события и видео |
| `succeeded`, событий нет | Система не обнаружила аксель; это не доказывает его отсутствие на видео |
| `failed` | Ошибка; сохраните её сообщение. Прерванные перезапуском задачи не повторяются автоматически |
| `cancelled` | Задача отменена |

«Аксель, номинал не определён» означает, что семейство найдено, но уровень не установлен. 1A и 2A обозначают номинальные 1,5 и 2,5 оборота; фактические обороты и докрут не измерены. Известна ошибка 1A → 2A. Независимая точность и обработка в реальном времени не подтверждены.

## Что передать по итогам

Укажите версию RC или commit, модель Mac, версию macOS, имя и длительность видео, известные элементы с временем на видео, ответ системы, длительность обработки и описание расхождения. Для ошибки добавьте `jobId`, сообщение ошибки и снимок экрана; для смещения скелета — кадр с видимым временем плеера. Передавайте материалы в согласованном канале проекта; личный ролик не требуется размещать в публичном issue.

Реальные снимки приёмки сохранены приватно: публикация соревновательного видео и его кадров не разрешена. На GitHub Pages доступны только два отдельно разрешённых демонстрационных ролика.

Контракт ответа: [Analysis API v1](../../runtime/API.md). Критерии и состояние приёмки: [Приёмка релиза](validation.md).
