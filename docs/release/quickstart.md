# FS_elem v0.2.1 — короткая инструкция кандидата

## Перед первым запуском исходного архива

Целевые системы — Mac с Apple Silicon (ARM64), macOS 13+, и Windows 10/11 x64. Нужен Node.js 24. Для Windows используйте [команды PowerShell](installation-windows.md); ниже приведены команды Mac. Новый пакет на обеих платформах ещё ожидает нативной проверки; [текущий статус](v0.2.1.md). Установка рассчитана на Python 3.12 для расчёта и Python 3.9 для позы. Первый этап требует интернета для пакетов и двух официальных ONNX-моделей. Их архивы занимают около 308 МБ; извлечённые модели — около 331 МБ. Дополнительно нужны место для Python/Node-зависимостей и временных файлов. 8 ГБ RAM — целевая конфигурация, без обещания скорости для любого видео.

Установите Node.js 24 и `uv` из официальных источников. В каталоге распакованного выпуска выполните:

```sh
uv python install 3.12 3.9
npm run setup:release -- --science-python "$(uv python find 3.12)" --pose-python "$(uv python find 3.9)"
```

Эта подготовка создаёт управляемые зависимости внутри комплекта и проверяет их версии и контрольные суммы. Не требуется открывать исследовательские пакеты или вручную выбирать модели. Для уже подготовленного локального комплекта этот этап повторять не нужно. Если вы используете свои установленные ARM64-интерпретаторы, передайте их пути тем же двум параметрам.

## Каждый следующий запуск

После установки откройте **FS_elem.command** на Mac или **FS_elem.cmd** на Windows двойным щелчком в каталоге комплекта. Он запускает локальный API и готовый интерфейс. Альтернатива из терминала:

```sh
npm run start:release
```

Адрес интерфейса — http://127.0.0.1:5174/analysis. Окно запуска должно оставаться открытым; `Ctrl+C` завершает обе службы. Одновременно запускайте один экземпляр и один анализ.

## Анализ полной записи

Нажмите «Выбрать видео для анализа», выберите MP4, MOV, M4V или WebM размером до 512 МиБ, затем начните анализ. Система ищет предполагаемые аксели; прочие прыжки и вращения не получают полного автоматического разбора в этом выпуске.

Во время расчёта интерфейс показывает этап и прогресс. После завершения нажмите карточку события или отметку на шкале: видео перейдёт к прыжку. При доступной позе включите точки и связи. Класс бывает 1A, 2A или «Номинал не определён». Если аксели не найдены, интерфейс покажет пустой результат; это не доказывает их отсутствие в записи.

Ссылка на анализ и кнопка «Открыть последний анализ» восстанавливают сохранённый результат без повторного распознавания. Результаты остаются в локальном каталоге этого комплекта; ссылка с другого компьютера их не переносит.

## Если произошла ошибка

Прочитайте сообщение интерфейса. Если задача сохранилась с ошибкой, её можно открыть снова и прочитать причину. Для нового расчёта выберите запись заново. Система не исправляет и не пропускает несогласованную временную шкалу молча.

При отсутствующих зависимостях выполните указанный в сообщении этап установки. Не удаляйте чужие или исторические окружения и результаты. Неверный хэш файла или незавершённое управляемое окружение останавливает подготовку; порядок безопасного восстановления приведён в [установке](installation.md).

GitHub Pages содержит статические сохранённые примеры, а не сервер анализа новых видео. Не закрывайте локальный запуск, пока идёт расчёт. Физическое вращение, недокрут и независимая точность здесь не подтверждаются.
