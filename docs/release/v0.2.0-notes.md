# FS_elem v0.2.0

Один локальный комплект для пути «полная запись → анализ → временные интервалы и предполагаемый 1A/2A → проверка на видео». Основа выпуска — принятый RC3; прежние модели, пороги и профиль CPU ORT 4/1 сохраняются.

- Загрузка полной записи, отображение этапов обработки и сохранённые результаты.
- Временные интервалы предполагаемых акселей, 1A/2A либо неопределённый номинал.
- Доступные реальные точки позы поверх исходного видео.
- Восстановление сохранённого результата и понятное сообщение для неуспешной задачи.
- Короткая инструкция единого запуска и явные требования установки.
- Вход **FS_elem.command** для Mac; локальный сервер использует готовую сборку интерфейса.

Платформа выпуска: macOS 13+, Apple Silicon ARM64, Node.js 24, Python 3.12 и 3.9. Скачиваемый исходный архив включает собранный интерфейс; зависимости и большие модели требуют управляемой локальной подготовки. Это не самостоятельный нативный установщик.

Результаты исследовательские и требуют проверки. Независимая точность, физические обороты, недокрут и работа в реальном времени не подтверждены. GitHub Pages остаётся статической демонстрацией. Новые приватные видео, кадры, результаты и модели в выпуск не входят.
