# Кандидат RC3: понятные ошибки видео

Предлагаемая версия: `axel-platform-rc3-2026-10-04`. Этот документ фиксирует снимок подготовки на 4 октября 2026: публикация ещё не выполнена. Итоговая приёмка выпуска и факт публикации фиксируются в GitHub Release notes для этого тега; статус снимка не обновляется задним числом.

Когда число декодированных кадров отличается от заявленного, интерфейс сообщает оба значения и останавливает анализ. При недостоверных временных метках появляется отдельное объяснение. Неизвестные, некорректные или противоречивые диагностические данные дают безопасное общее сообщение. Приватные пути, заголовки файла и traceback не передаются в публичное объяснение.

Ссылка на сохранённую неуспешную задачу восстанавливает её исходное состояние и объяснение. Такая задача не отображается как «аксели не обнаружены», не получает карточки предсказаний и не запрашивает результат или позу. Отмена, успешное завершение и ограничения времени/объёма сохраняют свой приоритет. Проверка числа кадров и временной шкалы остаётся обязательной; ошибки не обходятся.

Приняты серверные и клиентские исправления, включена новая production-сборка интерфейса. Сохранены 11 серверных и 37 интерфейсных проверок и отдельно прошедшая проверка передачи ошибки через публичный клиент. Дополнительный тест первоначально остановился из-за ошибочного импорта закрытой функции в тесте; исправлен только этот тест, успешные наборы не повторяли. В локальном API и браузере прошли 15 проверок трёх синтетических неуспешных задач, включая восстановление по ссылке и мобильное отображение. Это проверка ошибок на искусственных данных; полный новый анализ видео не выполняли. Независимая проверка сохранённых receipts и снимков этого синтетического прохода принята с оговорками области проверки; reviewer не выполнял повторный браузерный проход. На момент фиксации снимка отдельная проверка публичного пакета ещё ожидается.

Модели, выборка, пороги и CPU ORT 4/1 остаются прежними. 1A/2A и номинальные 1,5/2,5 оборота не являются измерением физических оборотов. Недокрут, независимая точность 70% и realtime не подтверждены. Соревновательный 1A по-прежнему может быть пропущен; известная ошибка 1A → 2A сохраняется.

Единственное историческое сравнение comp44 относится к RC2: 722,760365 → 433,113428 с, −40,0751%, прежние 2A/2A/1A. Источник знакомый, с TRAIN-overlap; результат не подтверждает ускорение RC3 или качество на новых спортсменах. [Подробная область проверки](validation.md).

В поставке сохранены три принятые публичные модели и два отдельно разрешённых демонстрационных ролика; их байты копировались и проверялись по SHA. Это отличается от загрузки моделей для анализа, декодирования новых источников или обучения. Новые личные видео, протоколы, исходные кадры, приватные заголовки и снимки синтетической браузерной проверки исключены. Старые отдельно разрешённые изображения демонстрации сохранены.
