# ЛЁД / FS_elem

Локальный прототип поиска акселя: загрузка видео, ход обработки, предполагаемые 1A/2A и точки позы на исходных кадрах.

**RC2 · 3 октября 2026.** Готовый анализ открывается по ссылке и кнопкой «Открыть последний анализ» без повторного распознавания. Добавлены время задачи и объяснение номинальных 1,5/2,5 оборота. Общая проверка локального пакета, API и интерфейса прошла.

На одном знакомом соревновательном прокате холодный запуск нового пакета с ORT 4/1 занял 433,11 с вместо сохранённых 722,76 с RC1 — на 40,08% меньше. В интерфейсе полное время задачи составило **7:13.76**. Получены прежние 2A, 2A, 1A; записанные точки позы совпали. Это одно последовательное сравнение: повторных замеров и репрезентативного набора видео нет. [Область проверки](docs/release/validation.md).

Первая платформа: macOS 13+, Apple Silicon, Node 24, Python 3.12 и 3.9. [Установка](docs/release/installation.md), [инструкция тестировщика](docs/release/quickstart.md). Основной запуск — `npm run start:release`; профиль 4/1 выбран по умолчанию, явный запасной вариант — `npm run start:release -- --profile ort2`. Модели и частота выборки сохранены; новое обучение в пакет не входит.

[Демонстрация](https://o1dkons.github.io/FS_elem/grant-demo/) содержит два отдельно разрешённых ролика. GitHub Pages остаётся статической демонстрацией; автоматический анализ запускается локально. Сохранённая ссылка на анализ относится к тому же локальному серверу и его каталогу задач; на другом компьютере результат по ней не появится.

1A/2A — предполагаемые номинальные классы. Физические обороты и недокрут не измеряются; независимая точность и realtime не подтверждены. Известная ошибка 1A → 2A на другом видео сохраняется. [Модель](docs/release/model-card.md), [сторонние компоненты](docs/release/third-party.md). Большие ONNX и FFmpeg доставляет установщик; в Git только три прежние очищенные модели. Приватные исходники, pose-кэши и снимки соревнований не поставляются.

[RC1 для отката](https://github.com/O1DKons/FS_elem/releases/tag/axel-platform-rc1-2026-10-03) остаётся доступным. `npm start` и `npm run import` относятся к прежнему редактору и требуют отдельной конфигурации и Python-окружения.
