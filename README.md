# FS_elem v0.2.1 — кандидат

Локальный анализ видео фигурного катания: загрузите полную запись, дождитесь обработки и проверьте предполагаемые аксели на исходном видео. Результат содержит временные интервалы, предполагаемый класс **1A / 2A** или **«Номинал не определён»**, а также доступные точки позы.

## Запуск

Целевые платформы: **macOS 13+ на Apple Silicon (ARM64)** и **Windows 10/11 x64**, CPU. После первой установки зависимостей откройте **FS_elem.command** на Mac или **FS_elem.cmd** на Windows. Этот вход запускает локальный API и готовый интерфейс.

v0.2.1 пока является кандидатом. На Mac прошли контролируемые проверки запуска и завершения процессов; установка и запуск самого нового пакета ещё ожидают проверки. Нативная установка Windows и работа через Проводник также пока не подтверждены. [Статус кандидата](docs/release/v0.2.1.md).

Для запуска из терминала в каталоге комплекта:

```sh
npm run start:release
```

Адрес интерфейса — **http://127.0.0.1:5174/analysis**. Оставьте окно запуска открытым; `Ctrl+C` останавливает обе службы. Не запускайте второй экземпляр на тех же портах.

Первый запуск после скачивания исходного архива требует подготовки зависимостей. Архив исходников и собранного интерфейса не содержит готовых Python-окружений, Node.js или больших ONNX-моделей. [Короткая инструкция](docs/release/quickstart.md) описывает подготовку и работу с видео; [подробная установка](docs/release/installation.md) — точные версии и проверку файлов; [Windows](docs/release/installation-windows.md) — команды PowerShell. После подготовки видео и расчёт остаются локальными.

## Работа с видео

1. Выберите видео в экране анализа и запустите обработку. Расчёт выполняется локально.
2. Дождитесь завершения. Нажмите найденный момент, чтобы проверить прыжок и доступные точки позы.
3. Сохраните ссылку на результат или используйте «Открыть последний анализ». Ссылка работает в том же локальном комплекте и каталоге задач. Открытие сохранённого результата не запускает новый расчёт.

Если обработка остановилась, интерфейс покажет причину или безопасное общее сообщение. Сохранённая неуспешная задача открывается с объяснением ошибки. Чтобы провести новый анализ, выберите видео заново. Расхождение кадров не считается доказательством повреждения записи.

## Что означает результат

Это исследовательский прототип. 1A/2A — предполагаемые номинальные классы, а 1,5/2,5 оборота — их номинальные определения. Физические обороты и недокрут не измеряются. Пропуск прыжка или неверный класс возможны; результат требует проверки. Независимая точность на всех новых видео и работа в реальном времени не подтверждены.

[Модель и ограничения](docs/release/model-card.md) · [сторонние компоненты](docs/release/third-party.md). Большие модели и FFmpeg устанавливаются локально; новые приватные видео, кадры, результаты и исследовательские пакеты в выпуск не входят.

[GitHub Pages](https://o1dkons.github.io/FS_elem/grant-demo/) показывает отдельно разрешённые сохранённые примеры. Для нового автоматического анализа используйте локальный экран `/analysis`.
