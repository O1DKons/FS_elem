# ЛЁД / FS_elem

Локальный прототип поиска акселя: загрузка видео, ход обработки, предполагаемые 1A/2A и точки позы на исходных кадрах.

**Кандидат RC3 · 4 октября 2026.** Добавлены понятные сообщения, если число прочитанных кадров расходится с данными файла или временные метки не проходят проверку. Для неподтверждённой причины показывается безопасное общее сообщение. Сохранённая неуспешная задача восстанавливается с объяснением ошибки без повторной загрузки, карточек успешного анализа и запросов результата или позы. Проверка исходной временной шкалы сохраняется: система не исправляет и не пропускает её молча. Расхождение кадров само по себе не доказывает повреждение файла.

Включена новая production-сборка интерфейса. Проверены код и передача ошибок, затем локальные API и собранный интерфейс на трёх синтетических неуспешных задачах. Это проверка обработки ошибок; нового распознавания видео или измерения качества RC3 не выполняли. Независимая проверка сохранённых свидетельств синтетического API/браузерного прохода принята; повторного прохода reviewer не выполнял. На момент фиксации этого снимка 4 октября 2026 проверка публичного пакета ещё ожидается, публикация не выполнена. Итоговую приёмку выпуска и факт публикации следует сверять с GitHub Release notes для тега RC3; этот снимок подготовки не обновляется задним числом. [Изменения RC3](docs/release/rc3-notes.md), [область проверки](docs/release/validation.md).

Готовый анализ открывается по ссылке и кнопкой «Открыть последний анализ» без повторного распознавания. Отображаются время задачи и номинальные 1,5/2,5 оборота. Сохранённая ссылка относится к тому же локальному серверу и его каталогу задач; на другом компьютере результат по ней не появится.

Первая платформа: macOS 13+, Apple Silicon, Node 24, Python 3.12 и 3.9. [Установка](docs/release/installation.md), [инструкция тестировщика](docs/release/quickstart.md). Основной запуск — `npm run start:release`; профиль CPU ORT 4/1 выбран по умолчанию, явный запасной вариант — `npm run start:release -- --profile ort2`. Модели, пороги и частота выборки сохранены.

**Исторический результат RC2.** На одном знакомом соревновательном прокате comp44 время pipeline составило **722,760365 → 433,113428 с, −40,0751%**; получены прежние 2A/2A/1A. Источник пересекается с историческим TRAIN. Это одно упорядоченное сравнение, не типичная скорость, независимая точность или новый результат RC3. Отдельный пропуск соревновательного 1A и известная ошибка 1A → 2A сохраняются.

1A/2A — предполагаемые номинальные классы с номинальными 1,5/2,5 оборота. Физические обороты, градусы недокрута и знаки `q`, `<`, `<<` не измеряются; независимые 70% и realtime не подтверждены. [Модель](docs/release/model-card.md), [сторонние компоненты](docs/release/third-party.md). Большие ONNX и FFmpeg доставляет установщик; в пакете только три прежние очищенные модели.

[Демонстрация](https://o1dkons.github.io/FS_elem/grant-demo/) содержит два отдельно разрешённых ролика. GitHub Pages остаётся статической демонстрацией; автоматический анализ запускается локально. Личные видео, протоколы, исходные кадры и снимки новых приватных проверок в поставку не включены.

[RC2](https://github.com/O1DKons/FS_elem/releases/tag/axel-platform-rc2-2026-10-03) и [RC1](https://github.com/O1DKons/FS_elem/releases/tag/axel-platform-rc1-2026-10-03) сохраняются как прежние поставки. `npm start` и `npm run import` относятся к прежнему редактору и требуют отдельной конфигурации и Python-окружения.
