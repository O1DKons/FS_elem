# ЛЁД / FS_elem

Локальный прототип поиска акселя: загрузка видео, ход обработки, предполагаемые 1A/2A и реальные точки позы на исходных кадрах.

**RC1 · 3 октября 2026.** Чистая установка и один полный анализ через интерфейс проверены. [Результаты проверки](docs/release/validation.md).

Первая платформа: macOS 13+, Apple Silicon, Node 24, Python 3.12 и 3.9. [Установка](docs/release/installation.md), [краткая инструкция](docs/release/quickstart.md). Новое обучение в установку не входит.

[Демонстрация](https://o1dkons.github.io/FS_elem/grant-demo/) показывает сохранённые результаты на двух разрешённых роликах; GitHub Pages просматривает свои видео без автоматического анализа.

1A/2A — предполагаемые номинальные классы. Физическое вращение и недокрут не измеряются; независимая точность и realtime не подтверждены. [Модель](docs/release/model-card.md), [сторонние компоненты](docs/release/third-party.md). Большие ONNX и FFmpeg доставляет установщик; в Git только три малые очищенные модели. Основной запуск — `npm run start:release`; `npm start` и `npm run import` относятся к прежнему редактору и требуют отдельной подходящей конфигурации и Python-окружения. Исходный dataset не поставляется; для чистой установки используйте команды выпуска.
