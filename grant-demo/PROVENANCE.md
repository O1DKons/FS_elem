# Происхождение демонстрации FS_elem

Состояние на 2 октября 2026. Этот автономный интерфейс показывает сохранённые ответы исследовательского запуска v4 от 1 октября; при открытии страницы модель не запускается. Показаны два реальных исходных видео, для которых сохранены эти ответы. Видео не заменены рисунком или кадрами другого спортсмена. Поверх изображения не рисуется неподтверждённая поза. Публичное размещение именно этих двух фрагментов разрешено пользователем 2 октября 2026, с подтверждением наличия разрешения на открытое размещение.

## Сохранённые примеры

`examples.js` содержит выбранные поля из двух настоящих завершённых JSON. SHA исходника, исходного полного JSON и конфига сохранены без изменения. Локальные абсолютные пути исключены. Только два выбранных исходных видео включены под нейтральными именами `media/example-1a.mp4` и `media/example-2a.mp4`; SHA файлов совпадает с sourceSha256 соответствующих receipts.

Источники JSON в исходном проекте: `work/axel-single-recipe-runtime-v1/runs-v4/personal-48-cold.json` и `personal-16-cold.json`. Подробный исходный отчёт: `docs/research/axel-single-recipe-runtime-2026-10-01.md`. Public snapshot содержит краткие обезличенные извлечения, и эти два разрешённых видео; полный dataset и полные receipts с приватными путями не включены.

Окна найдены автоматически. Названия «отрыв» и «приземление» в UI обозначают начало и конец такого окна; физический контакт лезвия отдельно не подтверждён. Номинал 1A/2A не является непрерывным измерением оборотов. `underrotation` и `physicalAirborneTurns` равны null.

Оба исходника присутствовали в обучении поиска и семейства. N=2/D=2/C=2/FP=0 в каждом режиме — проверка воспроизводимости на знакомых источниках, не независимая точность. Глобальная независимость спортсменов не проверена. Первые времена измерены с пустым pose-кэшем и имеющимися весами; повтор с кэшем не измеряет обработку нового видео. Работа в реальном времени и качество нового полного проката не подтверждены.

## Development-сводка

Принятая рабочая база на восьми личных размеченных попытках: N8/D6/C5/FP0, 1A C4/5, 2A C1/3. Это ограниченный набор развития. Источник текущего решения: `docs/research/audit-evidence-2026-10-01/nominal81d-matched-fit-v3-actual-posthoc-coordinator-acceptance-2026-10-02.json`, working_anchor retained, обе новые версии отклонены. Независимые 70% ещё не подтверждены. 3A и отдельная проверка докрута остаются последующими этапами.

## Локальное видео

Выбор файла создаёт временный browser object URL и даёт только просмотр. Файл не загружается на сервер; семейство, номинал и интервал для него не определяются. Переключение на сохранённый пример возвращает его собственный результат. Неподдерживаемый файл даёт явную ошибку просмотра.

## Просмотр и шкала

Кнопка «Посмотреть прыжок» воспроизводит выбранное автоматическое окно с небольшим контекстом до и после. Ползунок синхронизирован с currentTime видео, кнопки границ перематывают к сохранённым временам. Времена окна привязаны к исходной шкале PTS. Browser/container duration составляет3.015 и3.701667с, последние исходные PTS3.000 и3.686667с; около15мс хвоста контейнера не меняют сохранённые границы. Видео и воспроизведение не являются новой оценкой модели.
