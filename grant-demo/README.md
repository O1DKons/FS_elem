# FS_elem: демонстрация для гранта

Русская локальная веб-демонстрация исследовательского прототипа. Показывает два реальных сохранённых результата 1A/2A на двух разрешённых реальных тренировочных видео, временную шкалу и происхождение. Новое распознавание здесь не запускается.

Из корня репозитория:

```sh
python3 grant-demo/serve.py
```

Открыть http://127.0.0.1:5210/ . Нужны только Python 3 и современный браузер. Все ресурсы локальные, интернет не нужен. Также можно открыть `index.html` непосредственно как файл. Сервер публикует только папку grant-demo и слушает loopback. Другой порт: `python3 grant-demo/serve.py --port 5211`.

Доступно: переключение 1A/2A, перемещение по времени, переход к границам, просмотр своего локального видео без распознавания, раскрытие доказательств. Управление: Tab, Enter, стрелки на ползунке. При скрытии вкладки анимация останавливается. Видео относятся к тем же источникам, что и сохранённые результаты. Неподтверждённый скелет поверх видео не рисуется.
